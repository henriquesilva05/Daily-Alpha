Daily Alpha

Política de privacidade

Última atualização: 19 de novembro de 2026

O Daily Alpha (www.dailyalpha.pt) é um projeto pessoal e educativo que resume as notícias dos mercados para quem está a começar a investir. Esta página explica que dados são guardados, para quê e como os podes ver, corrigir ou apagar.

Responsável e contacto

O responsável pelo site é Henrique Silva. Para qualquer pedido sobre os teus dados, escreve para dailyalpha.app@gmail.com.

Dados guardados sempre (necessários)

  • Preferências no teu navegador: o tema, o idioma, as notícias que marcaste como lidas e a tua escolha sobre cookies ficam guardados só no teu navegador. Não chegam até nós.
  • Conta (se criares uma): o teu email, o nome que indicares e o teu portfólio (as transações que registares) ficam guardados no Supabase, para poderes entrar noutro aparelho. Só tu vês o teu portfólio.
  • Contagem de visitas da Vercel: conta as páginas vistas de forma agregada e sem cookies.

Entrar com o Google

Se escolheres «Continuar com Google», o Google partilha connosco apenas o teu nome, o teu endereço de email e a tua foto de perfil. Usamo-los só para criar e identificar a tua conta no Daily Alpha e para mostrar o teu nome no site. Não temos acesso à tua palavra-passe do Google, aos teus emails, contactos ou ficheiros, não vendemos estes dados nem os usamos para publicidade. O uso destes dados segue a Política de Dados do Utilizador dos Serviços API do Google, incluindo os requisitos de uso limitado.

Estatísticas, só com a tua autorização

  • PostHog (servidores na União Europeia): páginas vistas, cliques e funcionalidades usadas. Se tiveres sessão iniciada, essa utilização fica ligada à tua conta (ao identificador interno e ao email).
  • Microsoft Clarity: mapas de calor e gravações das visitas, para vermos onde as pessoas se perdem no site.

Estas ferramentas só são ativadas se carregares em «Aceitar» no aviso de cookies. Podes mudar de ideias a qualquer momento em «Privacidade e cookies», no rodapé do site.

Com quem são partilhados

Os dados ficam guardados nos serviços que fazem o site funcionar: Vercel (alojamento), Supabase (contas e portfólios), Google (só se entrares com o Google) e, se aceitares as estatísticas, PostHog e Microsoft Clarity. Não vendemos nem cedemos os teus dados a mais ninguém.

Durante quanto tempo

Os dados da conta e do portfólio ficam guardados enquanto tiveres conta. Podes apagar o teu portfólio a qualquer momento no site e pedir que a conta seja apagada por email.

Os teus direitos

Podes pedir para ver, corrigir ou apagar os teus dados, ou opor-te ao seu uso, escrevendo para dailyalpha.app@gmail.com. Também podes apresentar queixa à CNPD (Comissão Nacional de Proteção de Dados).

Aviso

O Daily Alpha resume notícias públicas para fins educativos e não é aconselhamento financeiro.
